# liquidation-of-organizations

Сборка сайта likvidacia-rb.com на Gulp. Исходники синхронизированы с архивом
продакшена likvidacia-rb.rar от 19.10.2026.

## Запуск

```sh
npm install
npm run build
npm run serve
```

Для `npm run serve` PHP должен быть доступен в PATH. Сайт откроется по адресу
http://127.0.0.1:8000. Этот режим выполняет PHP-обработчик формы.

`npm run dev` запускает Gulp, наблюдение за исходниками и статический предпросмотр
BrowserSync на порту 3000. Для проверки отправки формы используйте PHP-сервер
из `npm run serve`; его можно запускать одновременно с наблюдением Gulp.

## Структура

- `.src/index.html`, `_header.html`, `_footer.html` — шаблоны страницы.
- `.src/scss/` — стили, `.src/js/` — модули скриптов.
- `.src/js/form.js` — AJAX-отправка заявки в `/ajax/mail.php`.
- `.src/ajax/mail.php` — обработчик заявки и настройки получателя/отправителя.
- `.src/img/` — изображения, логотип и favicon.
- `docs/` — результат сборки для публикации.

Сборка очищает `docs/`, раскрывает HTML- и JS-подключения, компилирует SCSS,
создаёт минифицированные CSS/JS и копирует изображения, Swiper и PHP-обработчик.
Страница сохраняется как `index.php` для PHP-хостинга и `index.html` для
статического предпросмотра. Обе версии используют один шаблон.

## Публикация и почта

В корень сайта на PHP-хостинге загружайте содержимое `docs/`, включая
`ajax/mail.php`. Не размещайте сайт в подпапке: адрес обработчика в форме
начинается с `/ajax/` и отсчитывается от корня домена, как в продакшене.

Для реальной доставки писем на сервере должен быть настроен PHP `mail()`.
Параметры `$to`, `$fromName` и `$fromEmail` находятся в `.src/ajax/mail.php`;
после их изменения выполните `npm run build`. На статическом хостинге
(например, GitHub Pages) форма отправки писем через PHP не работает.

## Региональные SEO-страницы

Главная и шесть региональных страниц используют один шаблон `.src/_landing.html`.
Он сохраняет исходное оформление и все блоки главной: первый экран, этапы
ликвидации, сертификаты, преимущества, форму и контакты. Новых разделов,
карточек областей и пунктов меню нет.

Параметры главной находятся в `.src/index.html`. Региональные тексты,
заголовки и метаданные задаются в следующих файлах:

- `likvidaciya-ooo-v-minske.html` — Минск и Минская область.
- `likvidaciya-ooo-v-grodno.html` — Гродно и Гродненская область.
- `likvidaciya-ooo-v-breste.html` — Брест и Брестская область.
- `likvidaciya-ooo-v-vitebske.html` — Витебск и Витебская область.
- `likvidaciya-ooo-v-gomele.html` — Гомель и Гомельская область.
- `likvidaciya-ooo-v-mogileve.html` — Могилёв и Могилёвская область.

У каждой региональной страницы собственные title, description, H1 и canonical.
Географические сведения включены в существующие абзацы первого экрана,
описание работы с ООО/ИП и подпись формы. Адреса, телефоны и квалификация
специалиста остаются исходными; региональные офисы не заявляются.

Сборка создаёт HTML- и PHP-копию каждой страницы. Canonical у обеих копий
ведёт на HTML-адрес этой страницы. `.src/sitemap.xml` содержит главную и шесть
региональных адресов. `.src/robots.txt` указывает на карту сайта. Сборка
копирует оба файла в корень `docs/`; загружайте их вместе с сайтом.

При смене домена обновите canonical в `_landing.html`, sitemap.xml и robots.txt.
Индексация выполняется поисковиками после публикации: само наличие страницы
и sitemap не гарантирует её показ в выдаче. Очень похожие страницы могут
объединяться в одну группу дублей; см. [документацию Google о canonical](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls).

Общие коды верификации Google/Yandex и Яндекс.Метрика находятся в
`.src/_landing.html`. Изменяйте исходники, затем запускайте сборку.
